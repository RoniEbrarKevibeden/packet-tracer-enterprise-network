# Cisco Packet Tracer Enterprise Network Project

This academic project was developed for the Network Technologies course.

## Project Overview
The project simulates a small enterprise network in Cisco Packet Tracer. It includes:
- 4 IPv4 LANs
- 2 Cisco routers
- 4 switches
- 12 PCs
- 1 server
- Point-to-point WAN link
- Static routing
- DNS and HTTP services
- Connectivity testing with ping, ipconfig, and show ip route

## DNS/HTTP Server
A simulated DNS A record was configured inside Cisco Packet Tracer:
- ronikevibeden.com → 192.168.75.10

This domain works only inside the Packet Tracer simulation environment.

## Tools Used
- Cisco Packet Tracer
- IPv4 addressing
- Static routing
- DNS
- HTTP
